# Security policy

## Supported versions

Security fixes are provided for the latest tagged release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not include credentials, private transcripts, or client information in a
public issue.

The plugin does not grant permissions to agents or make network requests. It
does relay complete room messages to the addressed native agents and stores
the resulting transcript locally. Reports concerning provider-side retention
or an agent's own tool permissions should be directed to that provider.
